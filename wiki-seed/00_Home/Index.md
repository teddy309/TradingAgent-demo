# Hermes Paper Trading

현재: 조회 전용 기반. KIS 실연결은 사용자 키 입력 후 검증 필요.
투자 시장·종목·원금·주기·전략 승인·주문 한도는 미확정이다.

## 자료 위치

- 10_Research: 시장·종목 리서치와 출처
- 20_Strategies: 전략 초안과 버전
- 30_Decisions: 판단 당시 기록과 원장 등록 JSON
- 40_Daily/Generated: SQLite 기반 보고서 (재생성 가능)
- 40_Daily: 사람이 읽는 당일 해설
- 50_Reviews: 주간·전략별 회고
- 90_Templates: [[90_Templates/Research]], [[90_Templates/Strategy]], [[90_Templates/Decision]], [[90_Templates/Review]]
